# Python_misc
miscellaneous Python tools I use to solve my everyday problems ^_^

In the folder **Algorithmic Trading**, I implemented my own Simple Moving Average Indicator in order to capture buy signals in stock market.

In the folder **DSA** folder are my data structure and algorithm practice records.

In the folder **HDD backup**, I implemented a simple files backup scheme, which syncs files remotely and locally to other HDDs.

In the folder **salary_dataset** are the salary dataset I collected from government websites.

In the folder **yfinance**, I implemented stock price prediction program to help myself find buy signals.

In the folder **台灣行業職業分類與薪資**, I compiled a salary dataset ranked by yearly pay. The numbers are average, which may not reflect the true situation.(better reflected by median numbers).

In the file **password_generator.py**, I implemented a random password generator. This is important as a cyber threat counter measure.
